Cono Paleta Vaso Galleta

Un proyecto pensado para el día a día de una heladería.

Somos estudiantes de Desarrollo de Software de la Universidad Tecnológica de Comfenalco. Construimos Ice Cream para que un negocio real pueda controlar su inventario, registrar ventas y entender sus datos sin depender de hojas de cálculo sueltas.

  • Ventas registradas sin papeleo ni cuentas repetidas.
  • Stock que se actualiza después de cada venta y traslado.
  • Reportes y modelos predictivos para decidir qué vender mañana.

Todo el local, en una sola pantalla.

Seis herramientas que trabajan juntas: desde el ingreso de un helado al almacén hasta el reporte que te dice qué está funcionando.

Gestión de ventas

Registra cada transacción, aplica el recargo de tarjeta y actualiza la disponibilidad en el mismo momento.

Manejo de inventario

Supervisa el almacén y el mostrador. El sistema descuenta unidades después de cada venta y evita perder stock por desorden.

Base de datos MongoDB

Toda la información del negocio se centraliza en MongoDB, con una estructura flexible y consultas rápidas.

Panel estadístico

Consulta métricas del negocio en un tablero de Power BI integrado. Los datos se convierten en decisiones concretas.

Panel del vendedor

Un punto de venta claro para elegir productos, armar el carrito, buscar al cliente y cobrar sin pasos de más.

Memoria en caché

Las consultas frecuentes se resuelven más rápido con una capa de caché, para que el sistema responda al ritmo del mostrador.
